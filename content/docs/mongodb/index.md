# MongoDB

MongoDB stores JSON-like documents in collections. This section takes you from `mongosh` and CRUD through indexes, aggregation, transactions, security, backups, and production deployment.

## Learning path

Start with [documents and collections](/docs/databases), then practise CRUD and indexes before moving to aggregation, schema design, transactions, and Atlas operations.

> Keep credentials out of source control, use least-privilege database users, and test backup restores before calling a deployment production-ready.
