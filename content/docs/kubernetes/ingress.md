# Kubernetes Ingress & Routing

An **Ingress** manages external HTTP and HTTPS traffic access to Services inside a cluster. It provides Layer 7 load balancing, SSL/TLS termination, and name-based virtual hosting.

---

## 1. Ingress Resource vs Ingress Controller

```
[ Internet Traffic: https://docs.tashanto.com ]
                        │
                        ▼
       ┌─────────────────────────────────┐
       │ Ingress Controller (e.g. NGINX) │
       │ (Evaluates Ingress YAML rules)  │
       └──────────────┬──────────────────┘
                      │
        ┌─────────────┴─────────────┐
        │ /api                      │ / (frontend)
        ▼                           ▼
┌──────────────┐            ┌──────────────┐
│ Service: api │            │ Service: web │
└──────────────┘            └──────────────┘
```

- **Ingress Resource**: The YAML manifest defining your routing rules and TLS certs.
- **Ingress Controller**: The running proxy daemon (such as `ingress-nginx`, `Traefik`, or `AWS Load Balancer Controller`) that fulfills the Ingress rules.

---

## 2. Complete Ingress Manifest

```yaml
# ingress.yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: main-ingress
  namespace: default
  annotations:
    kubernetes.io/ingress.class: "nginx"
    cert-manager.io/cluster-issuer: "letsencrypt-prod"
    nginx.ingress.kubernetes.io/ssl-redirect: "true"
spec:
  tls:
    - hosts:
        - docs.tashanto.com
      secretName: tashanto-docs-tls # Auto-generated by cert-manager
  rules:
    - host: docs.tashanto.com
      http:
        paths:
          # Route /api to backend service
          - path: /api
            pathType: Prefix
            backend:
              service:
                name: api-service
                port:
                  number: 8080
          # Route all other traffic to web frontend
          - path: /
            pathType: Prefix
            backend:
              service:
                name: web-service
                port:
                  number: 3000
```

Apply the Ingress:
```bash
kubectl apply -f ingress.yaml
kubectl get ingress
```
