# Authentication and Authorization

Authentication proves identity; authorization decides what that identity may do. Learn secure cookies, sessions, JWT trade-offs, OAuth and OpenID Connect, password hashing, MFA, RBAC, CSRF, rate limiting, token rotation, and audit logging.

Frontend guards improve user experience, but only server-side authorization protects data.
