# Getting Started

This page explains how to navigate OpenDevDocs and get the most out of its content.

## Navigation

- Use the **sidebar** to browse topics within a section
- Use the **search** (keyboard shortcut: `Ctrl+K` or `Cmd+K`) to find anything
- Use the **breadcrumbs** at the top to navigate back

## Sections

Each section has a dedicated purpose:

1. **Docs** — comprehensive guides and references
2. **Commands** — CLI commands with flags and examples  
3. **Errors** — common errors with root cause and fix
4. **Recipes** — short, focused how-to patterns
5. **Roadmaps** — structured learning paths
6. **Packages** — library and package API references
7. **Tools** — developer tooling guides

## Reading Pages

Each page includes:

- A **title** and **description** at the top
- A **table of contents** on the right sidebar (for longer pages)
- An **Edit on GitHub** link to suggest improvements
