# GitHub Repositories & Collaboration

**GitHub** is the world's leading developer platform for hosting Git repositories, reviewing code, managing projects, and running automated CI/CD workflows.

---

## 1. Public vs. Private Repositories

- **Public Repositories**: Visible to anyone on the internet. Ideal for open-source libraries, documentation platforms (like OpenDevDocs), and developer portfolios.
- **Private Repositories**: Accessible exclusively to you and explicitly invited collaborators or organization teams.

---

## 2. Essential Repository Files

Every well-maintained repository should include:

1. **`README.md`**: The front page of your project explaining what the software is, how to install it locally, how to run tests, and how to contribute.
2. **`LICENSE`**: The legal open-source license (MIT, Apache 2.0, GPLv3) governing permissions, warranties, and commercial use.
3. **`CONTRIBUTING.md`**: Guidelines for external contributors regarding code style, branch naming, and pull request review standards.
4. **`.gitignore`**: List of local files (build artifacts, dependencies, secrets) that must never be tracked in Git.
