## Command

<Command>cd /path/to/directory</Command>

---

## Short Description

`cd` (Change Directory) changes the current working directory in your shell environment.

---

## Examples

### 1. Navigate to Home Directory

```bash
cd ~
# or simply:
cd
```

### 2. Move Up One Directory Level

```bash
cd ..
```

### 3. Return to Previous Working Directory

```bash
cd -
```

### 4. Navigate using Absolute Path

```bash
cd /var/log/nginx
```
