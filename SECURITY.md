# Security Policy

## Supported Versions

We actively maintain and support the latest release of OpenDevDocs.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

---

## Reporting a Vulnerability

The OpenDevDocs team takes the security of our application and users seriously.

If you discover a security vulnerability or sensitive bug within the codebase, dependencies, or infrastructure, please **do NOT open a public GitHub issue**.

Instead, report security vulnerabilities directly via:
1. **GitHub Private Vulnerability Reporting**: Click **Report a vulnerability** under the **Security** tab of our repository.
2. **Email**: Send details, proof-of-concept, and impact description to **mdtanvirahamdsanto987@gmail.com** with the subject `[SECURITY] Vulnerability Report`.

### What to Include:
- A description of the vulnerability and its potential impact.
- Clear steps or scripts to reproduce the behavior.
- Affected URLs, components, or files.

### Response Timeline:
- We acknowledge receipt of vulnerability reports within **48 hours**.
- We will provide status updates while investigating and patching the issue.
- Once fixed, a security advisory and credit will be published in the release notes.
